# aes-test-strong

Test target for the AES readiness advisor, seeded to represent a well-governed repository with strong shared knowledge signals.

## What lives here

A minimal but complete set of governance and knowledge files: CODEOWNERS, branch protection on main, a CI workflow, a Dependabot configuration, agent instructions, a CONTRIBUTING guide, an architecture note, an ADR log, and issue and PR templates.

## How to run

Nothing to run. This repo exists only as a scanner test target.

See docs/architecture.md and docs/adr/ for the decisions that shape this codebase.
